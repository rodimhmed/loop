# محاضرات إدارة الأعمال

موقع عربي بخط Amiri، يعرض جدول المحاضرات ومجلدات ملفات PDF بشكل متداخل، مع رابط Instagram إلى @rs6sc.

## تنظيم الملفات والمجلدات
ضع ملفات PDF ومجلداتك الفرعية داخل `pdf` كما هي. مثال:

```text
pdf/
├── المحاسبة/
│   ├── نظري/
│   │   └── lecture-01.pdf
│   └── عملي/
│       └── lecture-02.pdf
├── التسويق/
│   └── marketing-01.pdf
└── الاقتصاد الجزئي/
    └── economics-01.pdf
```

## تحديث فهرس المجلدات
بعد إضافة ملفات أو مجلدات أو تغيير أسمائها، افتح الطرفية داخل مجلد المشروع وشغّل:

```bash
python3 build_library.py
```

سيقرأ السكربت مجلد `pdf` وكل المجلدات الفرعية داخله، ثم ينشئ `library.json.js`. الموقع سيعرض المجلدات، ويمكن للزائر فتحها والتنقل بينها، وقراءة ملفات PDF أو تنزيلها. البحث يبحث في جميع المجلدات.

## النشر على GitHub Pages
1. شغّل `python3 build_library.py` بعد آخر تعديل على ملفات PDF.
2. أنشئ مستودعاً عاماً جديداً على GitHub.
3. ارفع محتويات هذا المجلد إلى جذر المستودع (لا ترفع ملف ZIP وحده).
4. افتح Settings ثم Pages.
5. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
6. اضغط Save وانتظر رابط النشر.

## ملاحظة
GitHub Pages لا يستطيع اكتشاف محتويات المجلدات تلقائياً أثناء عرض الموقع؛ لذلك ينشئ `build_library.py` فهرساً قبل الرفع. لا تحتاج إلى كتابة أسماء كل ملف يدوياً. الملفات في المستودع العام ستكون متاحة للجميع، فانشر فقط ما لديك إذن بمشاركته.
